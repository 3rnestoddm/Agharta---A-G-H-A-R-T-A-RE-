# Compendium

This folder holds the deep archive.

The front page should remain selective.
The compendium holds the full research machine.

Subfolders:

- `intake/` - first-pass artifact entries
- `sources/` - source cards
- `claims/` - atomic claim sheets
- `maps/` - map logic and ingress notes
- `symbols/` - motif index
- `synthesis/` - cross-source summaries
- `assets/source/` - raw source assets
- `assets/derived/` - annotated or transformed assets
